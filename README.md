# Advanced Calculator

A powerful scientific calculator built with Next.js, TypeScript, and React.

## Features

- **Basic Operations**: Addition, subtraction, multiplication, division
- **Scientific Functions**: 
  - Trigonometric: sin, cos, tan
  - Logarithmic: ln, log
  - Power functions: square, power, square root
  - Factorial and reciprocal
  - Mathematical constants: π, e
- **Memory Functions**: MC, MR, M+, M-
- **Advanced Operations**: Modulo, exponentiation
- **Responsive Design**: Works on desktop and mobile devices
- **Modern UI**: Beautiful gradient background with smooth animations

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the calculator.

## Deployment

This project is deployed on Vercel at [calc41.lynkr.cc](http://calc41.lynkr.cc)
